# Support

Before asking for help, check the README and the relevant guide in the [docs](docs/).

## Where to ask

- **Usage and setup questions:** Start a [GitHub Discussion](https://github.com/tomi3-11/sentinel-monitor/discussions) when available.
- **Bug reports:** Open a [bug report](https://github.com/tomi3-11/sentinel-monitor/issues/new?template=bug_report.yml) with the version, environment, reproduction steps, and relevant output.
- **Feature proposals:** Open a [feature request](https://github.com/tomi3-11/sentinel-monitor/issues/new?template=feature_request.yml). Search existing issues first.
- **Security vulnerabilities:** Follow [SECURITY.md](SECURITY.md). Do not post vulnerability details publicly.

## When reporting a problem

Include the Sentinel version, Python version, operating system, installation method, relevant configuration with secrets removed, the command you ran, and the complete error output where practical.

Please do not post passwords, access tokens, private keys, private URLs, or real webhook URLs.
