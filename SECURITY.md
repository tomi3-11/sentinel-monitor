# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Use GitHub's **Report a vulnerability** option in the repository's Security tab to submit a private vulnerability report, if that feature is available. Include:

- A clear description of the vulnerability and its potential impact.
- The affected version, commit, or component.
- Steps to reproduce the issue or a proof of concept, where safe.
- Any suggested mitigation, if known.

If private vulnerability reporting is unavailable, contact the repository maintainer privately through the contact options on the maintainer's GitHub profile. Do not publish exploit details while seeking a private reporting channel.

Please allow maintainers reasonable time to investigate and coordinate a fix before public disclosure. Do not access, modify, or delete data that does not belong to you while investigating a suspected vulnerability.

## Supported versions

Security fixes are currently applied to the latest released version. Users should upgrade to the latest release where possible.
